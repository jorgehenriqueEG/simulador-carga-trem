# Simulador de Carga de Trem
## Descrição do Problema
Calcular a distribuição de peso entre os vagões de um trem de carga considerando o peso máximo permitido por eixo.
## Requisitos
* Definir lista de vagões com peso e capacidade.
* Somar pesos dos vagões que excedem o limite de segurança.
* Reportar se o trem pode ser acoplado.
## Exemplo de Uso
Entrada: Vagões com pesos [45, 52, 48] e limite 50.
Saída: Vagões excedentes: 1 | Trem seguro: Não
